Нельзя открывать демо как файл

YouTube возвращает Error 153, потому что у страницы file:// нет HTTP Referer. Это ограничение YouTube, а не ошибка ролика.

Закройте эту вкладку и запустите:

demo\start-demo.cmd

Файл поднимет локальный HTTP-сервер и сам откроет рабочий адрес http://127.0.0.1:4173/demo/.
