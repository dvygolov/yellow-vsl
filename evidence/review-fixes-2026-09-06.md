# Исправления по code review — 6 сентября 2026

Изменения подготовлены локально поверх `a3e33ca`. Новые продуктовые фичи из последнего раздела плана (retry/resetProgress, отложенная загрузка, диагностика и процентные события) не добавлялись.

## Исправлено

- Loop учитывает актуальное состояние звука; pause/seek отменяют отложенный переход. Перед возвратом основного iframe проверяются движение времени и устойчивое воспроизведение, а не только значение PLAYING. Субтитры синхронизируются с зеркалом.
- Предзагрузка popup не открывает окно. Закрытие отменяет запуск, ожидающий готовности YouTube. Блокировка прокрутки учитывает все открытые окна и восстанавливает прежнее значение; фокус удерживается внутри диалога и возвращается на открывший элемент.
- Play после завершения начинает новый проход. Автоматический resume уважает отключённый autoplay. Явный язык субтитров имеет приоритет над настройкой конструктора, включая отложенное появление дорожек.
- Destroy отменяет загрузку и таймеры. AutoInit заново создаёт уничтоженный экземпляр. Ожидание готовности iframe ограничено тайм-аутом; ошибка сохраняет исходный код, останавливает фоновые действия и скрывает controls без помощи CSS сайта.
- Некорректные и пустые диапазоны отклоняются. При запуске другого экземпляра отменяется также ожидающее буферизации воспроизведение.
- Позиция, maxWatched и офферы разделены по экземплярам. Для постоянного хранения требуется id контейнера или storageKey/data-storage-key. Без них используется память. Записи v1 не удаляются и не импортируются в v2; конфигурация оффера входит в идентификатор открытия.
- Loop, captions, sticky, управление модальным фокусом/прокруткой, storage и таймеры выделены в отдельные модули. Добавлены декларации TypeScript и проверки интеграции; runtime-зависимостей нет.
- Версия API и баннеров получается из package.json. Deploy зависит от полного CI и получает проверенный артефакт того же коммита без повторной сборки.
