## Исправления popup

Плеер больше не переносит загруженный iframe между контейнерами при открытии и закрытии popup. Такой перенос перезагружал YouTube: быстрое нажатие Play после открытия могло потеряться, а повторное открытие сбрасывало состояние iframe.

Теперь iframe остаётся в одном контейнере на всём протяжении жизни плеера. Предзагрузка выполняется в закрытом popup; открытие и закрытие меняют только видимость. Исправление локального состояния паузы из 1.8.1 сохранено.

Добавлены браузерная проверка сохранения настоящего iframe browsing context и `npm run test:live:popup`: два последовательных открытия, запуск и закрытие настоящего YouTube в Chromium, Firefox и WebKit, без перезагрузки iframe, с проверкой паузы, таймеров и возврата фокуса.

Этот релиз включает весь набор исправлений [v1.8.0](https://github.com/dvygolov/yellow-vsl/releases/tag/v1.8.0). Для постоянного сохранения прогресса каждому плееру нужен уникальный стабильный id контейнера или storageKey. Новые продуктовые фичи не добавлялись.
